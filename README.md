# Real Size Watch — 테스트 빌드 0.1.0

아이폰을 손목 위에 올리면 화면이 가린 팔 부분을 가상 손목으로 채우고, 그 위에 시계를 실제 크기(1:1)로 그리는 iOS 앱 프로토타입입니다. Linear 프로젝트 **Real Size Watch (MVP)**(MIN-43~49)의 결정사항을 기준으로 만들었습니다. SwiftUI + AVFoundation만 사용하며 외부 패키지는 없습니다.

## 실행

1. `RealSizeWatch.xcodeproj`를 Xcode에서 엽니다.
2. Scheme `RealSizeWatch`, 실행 기기를 선택하고 **⌘R**을 누릅니다.
3. 실제 iPhone에서는 **Signing & Capabilities → Team**을 지정합니다. 필요하면 Bundle Identifier(`studio.once.realsizewatch`)도 바꿉니다.

iOS 17 이상, iPhone 세로 화면 전용입니다. Xcode 26.6에서 작업했습니다. `project.yml`을 고쳤다면 `xcodegen generate`로 프로젝트를 다시 만듭니다. 앱 아이콘은 프로젝트 루트에서 `swift Scripts/GenerateAppIcon.swift`로 다시 생성할 수 있습니다.

**시뮬레이터는 흐름 확인용입니다.** 계수는 해당 기기 기준으로 계산하지만 Mac 화면에서는 실제 크기가 아니고, 카메라가 없어 피부톤은 프리셋으로 고릅니다.

## 사용 흐름 (MIN-49)

1. **기기 식별 → 물리 스케일 확정.** 미등록 기기는 막지 않고 460ppi로 가정한 뒤 카드 보정을 권합니다.
2. **온보딩(최초 1회).** 화면 설정 안내 → 후면 카메라로 피부색 샘플 → 폰을 손목 위에 올리고 손목 굵기·밝기·색온도 맞추기. 완료하면 재실행해도 다시 묻지 않습니다.
3. **시계 스펙 입력 또는 선택.** 예시 7종이 들어 있고, `새 시계`/`스펙 편집`에서 직접 입력합니다.
4. **실제 크기 렌더링.** 가상 손목 위에 1:1 시계, 스트랩, 핏 판정을 표시합니다.
5. **팔에 올려 확인.** 화면을 탭하면 UI가 모두 숨겨집니다. 손목 화면에서는 밝기를 고정하고 자동 잠금을 끕니다.
6. **다른 시계로 전환.** 좌우로 밀거나 ‹ › 버튼을 누릅니다.

**자세:** 시계를 볼 때처럼 팔을 들고, 폰을 세로로 세운 채 손목 위에 가로질러 올립니다. 손목은 화면을 가로지르는 띠, L2L은 화면 세로, 크라운은 화면 오른쪽(기본)에 옵니다.

| 추가 발견 | 실외 불가 → 조도 임계치 넘으면 "그늘로 이동" | 전면 카메라 EV100 ≥ 11이면 경고 |
| MVP 제외 | 실사 3D, DB/브랜드 검색, 동시 비교, 입체 두께 | 넣지 않음 |

### 정정: mini는 `scale` 대신 `nativeScale`을 써야 합니다

12·13 mini는 375pt × 3 = 1125px로 그린 뒤 물리 패널 1080px로 축소합니다. 그래서 물리 픽셀/pt는 3이 아니라 **2.88**(`UIScreen.nativeScale`)입니다. Linear 표의 mini 값 0.16008mm/pt는 실제 0.15368mm/pt보다 **4.2% 큽니다**. L2L 48mm 시계가 약 50mm로 그려지는 차이로, 1mm 허용 오차를 넘습니다. 앱은 `mm/pt = 25.4 × nativeScale ÷ PPI`로 계산합니다. 다른 기기는 `nativeScale`이 `scale`과 같아 결과가 동일하고, 디스플레이 확대를 켠 경우도 함께 맞습니다. PPI 값은 Xcode 26.6 시뮬레이터 기기 프로필과 교차 확인했습니다. 연결 기록이 있는 iPhone 13 mini(`iPhone14,4`)가 바로 이 경우입니다.

## 임의로 정한 사항 (테스트 빌드용)

- **폰 자세와 축 방향.** 손목 띠는 가로, L2L은 세로입니다. 미확정 사항 결정 2·3·4의 "스트랩이 화면 상하로", "크라운 기본 오른쪽" 표현과 L2L이 손목 폭에 들어가야 한다는 MIN-48 전제를 모두 만족하는 배치입니다.
- **페이드 위치.** 10mm 페이드를 손목 띠 위아래 실루엣 경계에 적용합니다. 화면에서 맞춘 폭은 페이드 50% 지점입니다.
- **손목 밖 배경.** 기본 검정. 테스트 도구에서 회색·밝은 회색으로 바꿀 수 있습니다.
- **조명 자동 보정 모델.** 기준 대비 색온도 변화는 흑체 색 비율로 색도만 옮기고, 밝기는 2^ΔEV 배(0.5~2배 제한)로 맞춥니다. 150K·0.25EV 미만 변화는 무시합니다.
- **실외 임계치.** EV100 11. 실내 천장 측광 5~8, 그늘진 야외 11 이상 기준입니다.
- **고정 밝기.** 50%. 테스트 도구에서 조절합니다.
- **두께 표현.** 착용 화면은 두께에 비례한 그림자로, 편집 시트는 손목 곡률 위 측면도로 보여줍니다.
- **토노.** 케이스 길이는 min(L2L, 직경×1.2)이고, L2L과 같으면 러그 일체형으로 그립니다.
- **입력 범위.** L2L 25~70mm, 직경 20~60mm, L2L ≥ 직경, 러그 폭 ≤ 직경×0.8.
- **카드 보정 우선순위.** 카드 보정값이 있으면 기기 표보다 우선합니다. 기기 식별자에 묶어 물리 픽셀 단위로 저장하므로 디스플레이 확대를 바꿔도 유지됩니다.
- **예시 시계 7종.** 브랜드 없는 제너릭 스펙이며 MVP 제외 범위의 "시계 DB"가 아닌 시작용 샘플입니다.
- **피부 프리셋 6종.** 카메라가 없거나 거부된 경우의 대안입니다.

## 테스트 도구 (설정 › 테스트 도구)

결정사항을 실기에서 비교·검증하기 위한 스위치입니다. 기본값이 Linear 결정입니다.

- **v0.2 방식 비교: 시계 3% 축소.** 기획서 v0.2의 시야각 보정 방식. MIN-45 완료 기준인 보정 전/후 체감 비교용입니다.
- **미등록 기기처럼 동작.** 잠정 스케일·카드 폴백 흐름을 등록 기기에서 확인합니다.
- **손목 경계 페이드 0~16mm, 배경 톤, 고정 화면 밝기.**

## 코드

- `Domain/PhysicalScale.swift`: 기기 표, mm/pt 계산, 카드 보정.
- `Domain/WristFit.swift`: 손목 폭 보정, 둘레↔폭 변환, 핏 판정.
- `Domain/WatchSpec.swift`: 시계 스펙, 입력 검증, 예시.
- `Domain/SkinTone.swift`: 피부색, 조명 보정, 색 변환.
- `Domain/AppModel.swift`: 상태와 저장(UserDefaults JSON).
- `Rendering/`: 손목 띠·스트랩·케이스·다이얼·바늘 Canvas 렌더러, 측면도.
- `Camera/`: 후면 피부 샘플러(D65 WB 고정), 전면 조명 모니터.
- `Support/ScreenControl.swift`: 밝기 고정·자동 잠금 해제.
- `Features/`: 온보딩, 손목·카드 캘리브레이션, 착용 화면, 편집 시트, 목록, 설정.

## 테스트

```sh
xcodebuild -project RealSizeWatch.xcodeproj -scheme RealSizeWatch \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -parallel-testing-enabled NO CODE_SIGNING_ALLOWED=NO test
```

- **단위 27개.** PPI 그룹 값, mini nativeScale, 최신 기종 논리 폭 = 물리 패널 폭, 미등록 기기 폴백, 카드 보정(디스플레이 확대 포함), ×1.083, 둘레→폭이 MIN-48 표와 일치, 판정 밴드 경계, 판정 문구, 필수 값 검증, 같은 직경·다른 L2L의 화면 크기 차, 조명 보정, EV 계산, 재실행 후 온보딩 유지, 시계 전환·삭제, 카드 보정의 기기 귀속.
- **UI 3개.** 온보딩 → 렌더링 → 버튼·스와이프 전환 → 필수 값 없이는 저장 불가 → 새 시계 저장 → 재실행 시 온보딩 생략. 미등록 기기 배너 표시와 진행 가능 여부도 확인합니다. 나머지 하나는 화면 캡처용으로, `TEST_RUNNER_SCREENSHOT_DIR=<경로>`를 줄 때만 동작합니다.

### 검증 결과 (2026-10-08)

- iPhone 17 Pro 시뮬레이터 / iOS 26.5: 단위 27개 + UI 3개 통과.
- 실기기 대상(generic iOS) 빌드 성공(서명 없이).
- 화면 캡처: `Preview/iPhone17Pro/`.
- **실기기 미검증.** 실제 iPhone의 카메라 피부 샘플, 전면 카메라 조명 추적, 밝기 고정, 카드 1mm 실측은 기기에서 확인해야 합니다. 이 Mac에는 코드 서명 인증서가 없어 기기 설치는 하지 못했습니다.
- iPhone 13 mini 시뮬레이터 테스트는 Mac 디스크 공간 부족으로 중단했습니다. mini의 nativeScale 2.88은 시뮬레이터 기기 프로필(물리 1080px / 논리 375pt)로 확인했습니다.

## 실기에서 먼저 볼 것 (Linear 남은 리스크)

1. **카드 1mm 검증.** 설정 › `실물 카드로 정확도 확인`. 13 mini에서 nativeScale 정정이 맞는지 가장 먼저 확인합니다.
2. **손목 보정 계수 1.083.** 줄자로 잰 손목 폭과 앱의 "실제 손목 약 ○○mm" 비교.
3. **핏 판정 0.78 계수와 밴드.** 실제 시계 몇 개로 체감 비교.
4. **True Tone 영향.** 켠 상태와 끈 상태의 피부색 차이.
5. **단순 실루엣의 충분성.** 팔로 보이는지, 페이드 폭·배경 톤을 테스트 도구로 바꿔가며 확인.
